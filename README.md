# ZeroNG

Visual inspection for factories that have **no defect (NG) images yet**.

ZeroNG answers the three questions every inspection client asks before signing:

1. **How many images do we need?** Data-efficiency curve, few-shot vs. zero-shot.
2. **Will it survive real factory conditions?** Robustness benchmark: lighting, blur, misalignment.
3. **Can it run on a cheap factory PC?** CPU deployment, latency, PLC integration.

> Status: work in progress (weeks 1–2: baselines). Results tables are generated by
> `scripts/make_tables.py` from logged runs and will appear here once the benchmark is complete.

## Setup

Requires [uv](https://docs.astral.sh/uv/). The venv uses Python 3.11 (anomalib/OpenVINO compatibility).

```bash
uv sync                      # creates .venv with pinned deps (CUDA 12.6 torch on Windows/Linux)
uv run pytest                # unit tests for splits and factory metrics
```

## Data

Public datasets only. Licenses are recorded in `data/LICENSES.md`. Several datasets (e.g. MVTec AD)
are **non-commercial** (CC BY-NC-SA 4.0): this repository is a research/portfolio project, and models
trained on them must not be used commercially.

```bash
uv run python scripts/download_data.py --dataset mvtec_ad visa imagenette
```

Imagenette is only auxiliary training data for EfficientAD (its ImageNet penalty term), never an
evaluation set. Archives are verified against SHA-256 before extraction.

## Evaluation protocol

MVTec-style datasets ship no defect validation split. ZeroNG uses a documented, seeded split protocol
(`src/zerong/data/splits.py`): the official test set is split, stratified by defect type, into a
`val` part (threshold calibration) and a `test` part (final numbers only). A slice of the good
training images is held out as `val_good` for calibration in the true zero-NG setting.

The primary metric is **false reject rate at zero escape** (FRR at 100% NG recall), alongside
image/pixel AUROC and PRO for comparability with the literature.
